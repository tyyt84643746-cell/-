# Анимационные серии «Что если…»

Короткие вертикальные ролики (9:16, 1080×1920, 30 fps), нарисованные кодом: Python + Pillow + NumPy, сборка через FFmpeg, озвучка ElevenLabs.

## Серии

| Папка | Серия | Длина |
|---|---|---|
| `series/blackout` | «Блэкаут»: Москва зимой остаётся без света | ~119 с |
| `series/tridtsat-dney` | «Тридцать дней», серия 1 «Поверил только он» | ~89 с |

## Файлы серии

- `script.py` — текст озвучки по сценам и заголовки.
- `tts.py` — озвучка через ElevenLabs; сохраняет `vN.mp3` и таймкоды `vN.json`.
- `art.py` (в `blackout`) — общая графика и постоянные персонажи: Артём, Пётр Ильич, соседка.
- `chars.py` (в `tridtsat-dney`) — кот Кекс, баба Валя, Колян.
- `scenes.py` — сцены: функция на сцену, возвращает кадр по времени.
- `render.py` — субтитры, звук, рендер сцен в 4 потока и сборка MP4.

## Как собрать

```bash
pip install pillow numpy          # нужен ещё ffmpeg и шрифт DejaVu Sans Bold
cd series/tridtsat-dney
python3 render.py preview         # лист превью preview.jpg
python3 render.py                 # полный рендер
```

Озвучка уже лежит в папках, поэтому `tts.py` нужен только при изменении текста. Он требует доступ к `api.elevenlabs.io` и ключ ElevenLabs.

`tridtsat-dney` использует графику из `blackout/art.py`, папки должны лежать рядом.

## Паспорт главного героя

Артём: жёлтая куртка с капюшоном, тёмно-синяя шапка, серый рюкзак, налобный фонарик. Рисуется функцией `hero()` в `series/blackout/art.py` и одинаков во всех сериях.
